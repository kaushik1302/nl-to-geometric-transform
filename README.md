# Predicting Geometric Edit Parameters from Natural Language

IE 643 Course Project — Team DyoOptix (Kaushik Kuppili, Akash Gudi)

Given an edit instruction such as *"nudge the shape slightly to the left"*, predict the
2D similarity transform it implies — translation, rotation and uniform scale — and apply
it to images and masks.

**Status:** in progress. Done: transform maths and unit tests; GeoBench download and
analysis; dataset vocabulary. Next: dataset generator.

## Setup (Windows, PowerShell)

```powershell
git clone https://github.com/kaushik1302/nl-to-geometric-transform.git
cd nl-to-geometric-transform
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt --extra-index-url https://download.pytorch.org/whl/cpu
python -m pip install -e .
```

Check the setup:

```powershell
python tools\smoke_test.py     # libraries and both text encoders load
python -m pytest -v            # unit tests
```

## Data

- **GeoBench 2D** (Zhu et al., ICCV 2025) — external benchmark and source of real images
  and masks. Download with `python tools\download_geobench.py` (~2.3 GB, saved to
  `data/hf_cache`, not tracked by git).
- **Training data** — generated by this project (in progress).

## Key conventions

Full details in `spec/transform_spec.md`.

- Image origin at the top-left; **y points down**
- Positive rotation = **counter-clockwise on screen** (same as OpenCV)
- Model target: `[tx, ty, cos θ, sin θ, log s]`, with translation as a fraction of image width
